# Portfolio Designer Site

个人作品集网站，基于 React + Vite 构建。

定位：视觉设计师 / AI 设计师 / AI 训练师 / 品牌设计师。

## 本地运行

```bash
npm.cmd install
npm.cmd run dev
```

默认开发地址：

```text
http://127.0.0.1:5174
```

## 预览构建版本

```bash
npm.cmd run build
npm.cmd run preview
```

默认预览地址：

```text
http://127.0.0.1:4174
```

## GitHub Pages

项目已包含 GitHub Pages 自动部署配置。

推送到 GitHub 后，在仓库 `Settings -> Pages` 中选择 `GitHub Actions`，之后每次推送到 `main` 分支都会自动构建并发布。
